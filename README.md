# Pianista Online - Piano Virtual Gratis para Practicar Música

Una aplicación web interactiva y completamente gratuita para practicar piano desde tu navegador. Incluye un piano virtual con sonido real, metrónomo, grabación y reproducción de interpretaciones, acordes básicos y mucho más.

## 🎹 Características

- **Piano Virtual Interactivo**: Teclas que se pueden tocar con el mouse
- **Soporte para Teclado**: Usa las teclas de tu ordenador para tocar
- **Sonido Real**: Generación de audio usando Web Audio API
- **Metrónomo**: Mantén el ritmo mientras practicas
- **Grabación y Reproducción**: Graba tu interpretación y reprodúcela
- **Acordes Básicos**: Botones para tocar acordes comunes
- **Diseño Responsive**: Funciona en dispositivos móviles y de escritorio
- **Interfaz Moderna**: Diseño atractivo con animaciones suaves

## 🚀 Cómo Usar

### Instalación
1. Descarga todos los archivos del proyecto
2. Abre `index.html` en tu navegador web
3. ¡Listo para tocar!

### Páginas Disponibles
- **`index.html`** - Piano virtual principal con todas las funciones

### Controles del Piano

#### Teclas del Mouse
- Haz clic en las teclas blancas y negras del piano para tocarlas
- Las teclas se iluminan cuando están activas

#### Teclas del Teclado
- **Teclas blancas**: A, S, D, F, G, H, J, K, L, Z, X, C, V, B
- **Teclas negras**: W, E, T, Y, U, Q, R, I, O, P

### Controles de la Aplicación

#### Octava
- Selecciona la octava (3-6) para cambiar el rango de notas
- Octava 4 es la octava central (Do medio)

#### Tempo (BPM)
- Ajusta el tempo del metrónomo de 40 a 200 BPM
- Usa el slider para cambiar la velocidad

#### Metrónomo
- Haz clic en "Metrónomo" para activar/desactivar
- El botón se ilumina en rojo cuando está activo
- Mantiene el ritmo según el tempo seleccionado

#### Grabación
- Haz clic en "Grabar" para comenzar a grabar
- Toca las notas que quieras grabar
- Haz clic en "Parar" para terminar la grabación
- Usa "Reproducir" para escuchar tu grabación
- "Limpiar" borra la grabación actual

#### Acordes
- Haz clic en los botones de acordes para tocarlos
- Incluye acordes mayores y menores básicos:
  - Do Mayor (C)
  - Fa Mayor (F)
  - Sol Mayor (G)
  - La Menor (Am)
  - Re Menor (Dm)
  - Mi Menor (Em)

## 🎵 Notas Musicales

El piano incluye las siguientes notas en cada octava:
- **Teclas blancas**: C, D, E, F, G, A, B
- **Teclas negras**: C#, D#, F#, G#, A#

## 📱 Diseño Responsive

La aplicación se adapta automáticamente a diferentes tamaños de pantalla:
- **Escritorio**: Piano completo con todas las funciones
- **Tablet**: Piano escalado con controles reorganizados
- **Móvil**: Piano compacto optimizado para pantallas pequeñas

## 🎯 Consejos para Practicar

1. **Comienza con el metrónomo**: Usa el metrónomo para mantener un ritmo constante
2. **Practica escalas**: Toca las notas en secuencia (C, D, E, F, G, A, B, C)
3. **Experimenta con acordes**: Usa los botones de acordes para aprender progresiones
4. **Graba tu práctica**: Graba tus interpretaciones para escuchar tu progreso
5. **Cambia de octava**: Experimenta con diferentes rangos de notas

## 🔧 Personalización

Puedes personalizar la aplicación modificando:
- **Frecuencias**: Ajusta las frecuencias de las notas en `script.js`
- **Estilos**: Modifica los colores y animaciones en `styles.css`
- **Acordes**: Agrega nuevos acordes en el objeto `chords`
- **Controles**: Cambia las teclas del teclado en los event listeners
